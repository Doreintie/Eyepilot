EyePilot.register({
  id: 'my-plugin',
  name: '我的眼控插件',
  mount(root, ctx) {
    // ctx.gaze    当前视线 {x, y, valid}
    // ctx.health  眨眼率 / 视距 / 疲劳指数
    // ctx.onFrame(cb) 每帧回调
    root.innerHTML = '<h3>Hello, eyes!</h3>';
  }
});

控制方式

眼控

眼控读虹膜，精细但要校准、对头位敏感；头部模式只读头部转角，极稳、免校准，代价是要用转头来移动光标。

眼控读虹膜，最精细，需要校准。

范围越小转头越省力；死区越大越稳；精修范围决定虹膜能“拉”动多少。

手机双摄

未连接

手机当第二视角：架在屏幕侧上方 30–45°，和电脑摄像头同时看脸。两路融合能压抖动、躲镜片反光。画面不出手机，只传 478 个关键点（约 3 KB/帧）。

—

视线微调

偏移 0 , 0 px

光标整体偏上/偏下、或「越往右越偏」：点「五点精细对齐」，依次盯住中心 / 上 / 下 / 左 / 右各 2 秒，横纵两轴的偏移与增益会一起重算。小范围偏差也可以用方向键推。

每次 12px，偏移保存在本机。

使用中自校准

0 次 · 0 , 0 px

你每用眼睛点中一个按钮，程序就获得一个“大致落点已知”的样本，用来自动补偿头位变化带来的整体漂移。不需要你做任何操作。

头部转动后，多点击几次就会重新收敛。

灵动岛

桌面版

屏幕顶部常驻的小面板，可拖动、可展开。显示眨眼频率、用眼时长等；指标异常时会自动弹开提醒。只在桌面版（EyePilot.exe）里浮在桌面上，网页版这里只做预览。

自定义内容也可以由外部程序写入。

EyePilot · 瞳行，校园黑客松参赛作品。技术栈：MediaPipe Face Landmarker（478 点）+ 虹膜相对位移特征 + 岭回归视线映射 + 一欧元滤波 + 行为统计模型。无需专用硬件，普通笔记本摄像头即可运行。
