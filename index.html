插件 API · 十行接入

JS / 浏览器
EyePilot.register({
  id: 'my-plugin',
  name: '我的眼控插件',
  mount(root, ctx) {
    // ctx.gaze    当前视线 {x, y, valid}
    // ctx.health  眨眼率 / 视距 / 疲劳指数
    // ctx.onFrame(cb) 每帧回调
    root.innerHTML = '<h3>Hello, eyes!</h3>';
  }
});

也可以只用一条事件：window.addEventListener('eyepilot:click', e => ...)，把眼控点击映射到任意网页元素。

关于

v1.0.0

EyePilot · 瞳行，校园黑客松参赛作品。技术栈：MediaPipe Face Landmarker（478 点）+ 虹膜相对位移特征 + 岭回归视线映射 + 一欧元滤波 + 行为统计模型。无需专用硬件，普通笔记本摄像头即可运行。

本作品不构成医疗建议。若持续眼干、眼痛或视力模糊，请就医。
