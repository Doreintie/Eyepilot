# 插件开发指南

EyePilot 把眼动信号做成一层输入层，而不是一个封闭的功能。扩展方式有两种：

1. **应用内插件**：注册一个面板，直接拿到每帧的视线与健康指标（最快）。
2. **外接程序桥**：把注视点通过 HTTP / WebSocket 推给浏览器之外的进程（最通用）。

---

## 一、应用内插件

### 1.1 最小示例

在 `index.html` 的 `main.js` 之后加一行 `<script src="./my-plugin.js"></script>`，
或在你自己的模块里 `import './plugins.js'`：

```js
EyePilot.register({
  id: 'my-plugin',                 // 唯一 id，同时用于启用状态存储
  name: '我的眼控插件',
  tagline: 'One-line description',
  icon: '<svg viewBox="0 0 24 24"><circle cx="12" cy="12" r="8"/></svg>',
  description: '插件中心里显示的介绍文字。',
  tags: ['演示', '无障碍'],

  mount(root, ctx) {
    root.innerHTML = '<h3>Hello, eyes!</h3><p data-out>--</p>';

    const out = root.querySelector('[data-out]');
    ctx.onFrame((frame, gaze) => {
      if (!gaze.valid) return;
      out.textContent = `视线：${Math.round(gaze.x)}, ${Math.round(gaze.y)}`;
    });

    ctx.onCleanup(() => { /* 清除定时器、事件监听 */ });
  },
});
```

保存后刷新页面，插件中心会自动出现这张卡片。

### 1.2 生命周期

| 阶段 | 调用 | 你需要做什么 |
| --- | --- | --- |
| 注册 | `EyePilot.register(def)` | 声明元信息，不要在这里碰 DOM |
| 打开 | `mount(root, ctx)` | 渲染面板，注册帧回调与清理函数 |
| 运行 | `ctx.onFrame(cb)` | 每帧（约 30fps）收到 `frame` 与 `gaze` |
| 关闭 | `unmount(root, ctx)`（可选）→ 清理函数 | 停掉定时器、解绑监听 |

面板关闭时，`onFrame` 回调会自动解绑；但定时器、`requestAnimationFrame`、
`window` 监听必须自己清理，否则会泄漏。

### 1.3 `ctx` API

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `ctx.onFrame(cb)` | `(frame, gaze) => void` | 注册帧回调，返回取消函数 |
| `ctx.onCleanup(fn)` | `(fn) => void` | 面板关闭时执行 |
| `ctx.getGaze()` | `() => Gaze` | 当前视线快照 |
| `ctx.getFrame()` | `() => Frame` | 当前帧原始特征 |
| `ctx.getMetrics()` | `() => Metrics` | 眨眼率 / 视距 / 疲劳等聚合指标（1Hz 更新） |
| `ctx.settings` | `object` | 用户设置（眨眼点击时长、平滑强度等） |
| `ctx.setStatus(text, kind)` | `void` | 面板右上角状态胶囊，`kind`: `on` / `warn` / `bad` |
| `ctx.toast(title, body, kind)` | `void` | 全局提示 |
| `ctx.close()` | `void` | 关闭当前面板 |
| `ctx.app` | `object` | 全局状态（只读使用） |

### 1.4 数据形状

```ts
type Gaze = {
  x: number; y: number;          // 屏幕像素坐标
  nx: number; ny: number;        // 归一化 0..1
  valid: boolean;                // 置信度足够且视线在屏幕内
  confidence: number;            // 0..1
  outside: boolean;              // 预测点跑到屏幕外
  reason: 'ok' | 'blink' | 'noface' | 'outside' | 'lowconf' | 'uncalibrated';
  ts: number;
};

type Frame = {
  present: boolean;              // 是否检测到人脸
  open: number;                  // 眼睛睁开度 0..1
  blinkL: number; blinkR: number; // blendshape 闭眼分数
  distanceCm: number;            // 估算视距
  lightLux: number;              // 相对照度
  lightLuma: number;             // 原始画面亮度 0..255
  yaw: number; pitch: number;    // 头部姿态（归一化特征）
  fps: number;
};

type Metrics = {
  blinkRate: number;             // 次/分
  blinkDur: number;              // 平均眨眼时长 ms
  perclos: number;               // 闭眼时间占比 %
  distance: number;              // cm
  light: number;                 // 相对照度
  focus: number;                 // 0..100
  fatigue: number;               // 0..100
  health: number;                // 0..100
  minutes: number;               // 连续用眼分钟
  reliable: boolean;             // 数据是否足够可信
};
```

### 1.5 全局事件

不想写插件，也可以只监听事件：

```js
window.addEventListener('eyepilot:click', (e) => {
  const { target, gaze } = e.detail;
  console.log('眼睛点击了', target, gaze.x, gaze.y);
});
```

元素被眼控命中（进度环开始走）时会加 `.is-target` 类，可用于自定义高亮。

### 1.6 设计约定

- **不要在 `onFrame` 里做重活**：每帧只有 ~33ms，绘制请用 canvas，DOM 更新做节流。
- **尊重 `gaze.valid`**：无效时不要猜测，宁可暂停。
- **大目标、慢动作**：眼控适合 ≥48px 的目标与 ≥600ms 的停留，别做「眼控画图」这种精细操作。
- **可回退**：任何眼控交互都应该能用鼠标完成，眼控是增强而不是唯一路径。
- **清理**：`setInterval`、`requestAnimationFrame`、`window` 监听都要在 `onCleanup` 里释放。

## 二、外接程序桥（浏览器之外）

`tools/gaze-bridge.py` 是一个零依赖的接收器：它同时提供 HTTP 接收端和一个可视化页面。

```bash
python tools/gaze-bridge.py
# 接收端 http://127.0.0.1:8765/gaze
# 可视化 http://127.0.0.1:8765/
```

打开 EyePilot（演示模式也可以），在浏览器控制台粘贴：

```js
setInterval(() => {
  const g = window.EyePilot.state.gaze;
  fetch('http://127.0.0.1:8765/gaze', {
    method: 'POST',
    mode: 'no-cors',                       // 简单请求，不触发预检
    headers: { 'Content-Type': 'text/plain' },
    body: JSON.stringify({ x: g.x, y: g.y, valid: g.valid })
  });
}, 100);
```

然后打开 `http://127.0.0.1:8765/`：一个光点会跟着你的视线移动。
这就是外接程序的最小形态——任何本地进程（Python / Node / C# / Electron）都可以订阅这路信号。

**接到桌面应用**的典型做法：

```
EyePilot（浏览器）
   └─ WebSocket/HTTP → 本地桥（Python/Node）
        ├─ Electron 透明置顶层：把注视点画在桌面上，点击时转发给系统 API
        ├─ OBS / 直播工具：用注视点驱动画面缩放或高亮
        └─ VS Code 插件：用视线定位代码行、滚动文档
```

> 注意：当前 Demo 的桥接是「外部脚本主动拉取 + 转发」，不是应用内置的网络功能。
> 这是刻意的隐私选择——默认不向外发送任何数据，是否外发由使用者显式开启。

## 三、内置插件参考

| 插件 | 文件 | 用到的能力 |
| --- | --- | --- |
| 眼控阅读 | `src/plugins/reader.js` | 视线在面板内的相对位置 → 滚动速度；`getBoundingClientRect` 做坐标换算 |
| 眼控训练 | `src/plugins/game.js` | 视线 → canvas 坐标；注视停留计时、命中判定、反应时统计 |
| 专注番茄钟 | `src/plugins/focus.js` | 视线是否落在面板内 → 走神判定；与 `getMetrics().focus` 联动 |

三个插件都不到 200 行，可以直接复制一份改造成自己的。
