EyePilot · 瞳行 — 使用说明
========================================

这是什么
--------
用电脑摄像头做眼动追踪：让眼睛代替鼠标操作界面，同时实时分析用眼健康。
所有视频画面都只在这台电脑的浏览器里处理，不会上传到任何服务器。

运行要求
--------
- Windows 10 / 11（64 位）
- Edge 或 Chrome（推荐最新版）
- 一个能用的摄像头（没有摄像头也能用「演示模式」）

三步开始
--------
1. 把压缩包完整解压到一个文件夹（不要在压缩包里直接双击）
2. 双击「启动.bat」
3. 浏览器会自动打开 http://127.0.0.1:8848/
   点右上角「启动相机」→ 允许摄像头 → 完成九点校准（约 30 秒）

首次使用建议（直接决定精度）
----------------------------
- 坐姿距离：脸离屏幕 50–65 cm，大约一臂
- 脸放在画面中央，占画面宽度 1/3 左右（25–30%）
- 眼睛与屏幕上 1/3 齐平，稍微俯视，别仰头
- 摄像头尽量与屏幕同高，不要仰拍
- 光从正面来，不要背对窗户（逆光最容易失败）
- 校准页顶部有一个状态提示：显示「人脸正常」再开始
- 校准完成后，注视任意磁贴 0.8 秒即可打开，全程不用鼠标
- 光标如果整体偏上/偏下、或越往右越偏：设置 → 视线微调 → 「五点精细对齐」，
  依次盯住中心 / 上 / 下 / 左 / 右各 2 秒，两轴的偏移和增益会一起重算
- 觉得光标有点抖：设置 → 平滑强度往右调（越大越稳，跟随略慢）
- 想退出眼控：按 Esc，或直接点右上角「演示」切回鼠标

手机当第二摄像头（v1.4.0）
--------------------------
1. 关掉当前服务，改用：python serve.py --lan
2. 终端会打印「在手机浏览器打开：https://192.168.x.x:8848/phone.html?t=xxxxxx」
3. 手机和电脑连同一个 Wi-Fi，用手机浏览器打开这个地址
   首次提示「连接不安全」，选「高级 → 继续访问」（自签证书，正常）
4. 手机上点「开始推流」，把手机架在屏幕侧上方 30–45°
5. 电脑上：设置 → 手机双摄 → 「手机五点对齐」→ 再选「融合」
画面不出手机，只把 478 个关键点（约 3 KB/帧）发给电脑。

四种控制方式 / 护眼训练
----------------------
- 设置 → 控制方式，可以一键切换
- 眼控模式：读虹膜，最精细，但需要校准，头动了要重新对齐
- 混合模式（推荐）：头部负责粗定位，虹膜只在 110px 内精修；头不动时几乎不抖
- 头部模式：读头部转角，不用校准、静止时完全不抖，代价是要转头
- 仅鼠标：暂停眼控，护眼监测继续
- 头部 / 混合模式偏了：点「重新归中」，把当前头部位置当成屏幕中心
- 左侧「护眼」页有六节眼保健操（每节 20 秒）和科学用眼建议

灵动岛与托盘（桌面版）
----------------------
- 屏幕顶部会有一个小面板：显示眨眼频率、用眼时长、疲劳；点右侧箭头展开
- 它可以直接用鼠标拖动到任意位置；指标异常时会自动弹开提醒
- 想换内容：设置 → 灵动岛，勾选要显示的项，或在“自定义”里填正在播放的歌
- 托盘：关闭窗口不会退出，程序收到右下角托盘继续记录；右键托盘图标可以
  重新校准、五点对齐、暂停眼控、显示/隐藏灵动岛或退出

没有摄像头 / 摄像头打不开
------------------------
- 点右上角「演示」：用鼠标位置模拟视线，健康看板、AI 教练、插件都能正常演示
- 权限被拒：点地址栏左侧的锁 / 相机图标 → 把「摄像头」改成「允许」→ 按 F5
- 一定要通过 http://127.0.0.1 访问，直接双击 index.html 浏览器不会给摄像头权限
- Windows 还要确认：设置 → 隐私和安全性 → 相机 → 允许桌面应用访问相机

macOS / Linux
-------------
本压缩包内的 runtime 是 Windows 版。Mac / Linux 需要 Python 3.9+，
在终端进入本目录后执行：python3 serve.py

退出
----
关闭那个黑色命令行窗口即可。

隐私
----
- 视频帧只在浏览器内由本地模型处理，没有任何一帧离开这台设备
- 只有匿名的数值指标保存在浏览器本地，可在「设置 → 数据与隐私」里一键清除
- 如果配置了在线大模型，发送的也只有数值 JSON，不含图像

常见问题
--------
- 提示端口被占用：程序会自动换到 8849、8850…，以命令行里显示的地址为准
- 页面白屏：确认是从「启动.bat」打开的，按 F5 刷新
- 校准提示「样本太少」：把脸移到画面中间、距离调到 50–65 cm、避开背后强光后重试
- 提示「视线已离开屏幕」但其实在看屏幕：先做一次「五点精细对齐」；
  如果仍频繁出现，说明增益偏差较大，重做一次校准
- 头挪动之后光标偏了：不用整套重校准，点几次按钮让它自校准，
  或者做一次五点精细对齐（10 秒）
- 浏览器提示「无法访问此网站」：命令行窗口可能被关掉了，重新双击「启动.bat」

关于
----
EyePilot · 瞳行，校园黑客松参赛 Demo。
技术栈：MediaPipe Face Landmarker（478 点）+ 虹膜特征 + 岭回归视线映射 + 行为统计模型。
